# 서울 고령 보행자 교통사고 분석

> **사고는 보호구역 밖에서 집중된다 — 노인보호구역은 어디를 보호하고 있나?**
>
> 2025년 서울 **고령 보행자 사고다발지역 71곳 중 59곳(83.1%)이 확보된 노인보호구역 경계와 겹치지 않았다.** 이 수치는 보호구역 밖에서 발생한 개별 사고의 비율이 아니다. 또한 공식 연도별 지정 명단에 있는 일부 시설이 API 경계 자료에는 없어, 83.1%는 **확보된 API 경계 기준의 잠정 비교 결과**다.

서울 25개 자치구의 고령 보행자 교통사고 통계에 인구·생활인구·노인보호구역 공간정보를 결합해, 처음의 질문이 어떻게 달라졌는지 기록한 **데이터 저널리즘 프로젝트**입니다.

- **최초 질문:** 동대문구는 왜 고령 보행자 사고가 가장 많이 발생한 지역인가?
- **현재 질문:** 노인보호구역 지정은 실제 고령 보행자 사고 감소로 이어졌는가? (기존 공간 배치 연구와 별도의 후속 질문)
- **현재 단계:** 분석 1~12 완료. 분석 13(서울시 지정·관리 근거)은 정보공개청구 답변 대기. 별도 후속 연구인 **지정 전후 고령 보행자 사고 감소 여부**는 자료 전처리·탐색적 공간 비교를 진행했고, 한국도로교통공단 사고 원자료 정보공개청구 답변을 기다리고 있습니다. RAG 챗봇과 웹 대시보드는 후속 구현 목표입니다.

## 1. 프로젝트 소개

처음에는 동대문구의 높은 사고 건수가 고령인구 규모 때문인지 살펴봤습니다. 서울 전체를 비교하자 고령인구가 비슷한 도봉구와의 차이가 눈에 띄었고, 2022~2025년 사고 통계와 2025년 평균 고령 생활인구를 비교해도 차이가 남았습니다.

이후 노인보호구역 경계 기록 수를 서울 25개 자치구의 사고 발생 수준과 비교했습니다. 지정 규모만으로 뚜렷한 패턴이 보이지 않자 질문을 **‘몇 곳이나 지정되었나’에서 ‘실제 사고가 집중된 곳과 경계가 겹치는가’**로 옮겼습니다.

이 프로젝트의 결론은 노인보호구역의 *사고 예방 효과가 없다*는 것이 아닙니다. **서울 전역의 확인된 사고다발지역 상당수가 보호구역 경계와 겹치지 않는다는 사실**과, 그 결과가 실제 지정·관리 과정에 얼마나 반영되는지에 관한 질문입니다.

## 3. 분석 방법

기본 분석은 Python·pandas와 Google Colab에서 진행했습니다. 공간 비교에는 사고다발지역의 **GeoJSON Polygon**과 노인보호구역의 **WKT Polygon** 경계 정보를 사용했습니다.

1. **지역 비교:** 서울 25개 자치구의 고령 보행자 사고 건수, 고령인구 1만 명당 사고 건수, 전체 보행자 사고 중 고령 사고 비중 산출
2. **인구와 사고의 관계:** 피어슨 상관분석·단순 선형회귀분석으로 일반적인 경향과 크게 벗어나는 지역 확인
3. **연도별 비교:** 2022~2025년 동대문구·도봉구 사고 건수 비교
4. **생활인구 비교:** 2025년 남녀 65~69세 및 70세 이상 시점별 생활인구를 합산한 뒤 연중 평균 계산
5. **보호구역 지정 규모 비교:** 25개 자치구의 API 경계 기록 수와 고령인구 대비 사고 건수를 산점도로 비교
6. **공간 중첩 비교:** 사고다발지역 폴리곤과 노인보호구역 폴리곤이 겹치거나 경계에서 접촉하는지 확인

고령인구 1만 명당 사고 건수 = 사고 건수 ÷ 해당 인구 × 10,000

생활인구는 `250_LOCAL_RESD_GU_2025.csv`에서 남녀 65~69세 및 70세 이상을 합산하여 같은 자치구의 시간별 값을 연중 평균했습니다. 2025년 365일, 자치구별 8,760개 시점을 사용했습니다. 생활인구는 체류 규모 추정치이며 보행량을 직접 측정한 값은 아닙니다.

## 4. 주요 발견

### 4-1. 출발점: 동대문구의 높은 사고 발생 수준

2025년 서울 25개 자치구의 고령 보행자 사고는 총 **2,060건**이었습니다.

| 지표 | 주요 결과 |
|---|---|
| 고령 보행자 사고 건수 | 동대문구 **132건, 서울 1위** |
| 고령인구 1만 명당 사고 건수 | 중구 **22.08건, 1위** / 동대문구 **18.14건, 2위** |
| 전체 보행자 사고 중 고령 보행자 사고 비중 | 강북구 **42.00%, 1위** / 동대문구 **37.08%, 3위** |

절대 건수와 인구 대비 발생 수준, 고령 사고 비중은 서로 다른 지표이며 순위도 다릅니다.

### 4-2. 질문의 변화: 거주인구가 비슷한 동대문구와 도봉구는 왜 다른가?

서울 25개 자치구에서 고령인구와 사고 건수의 상관계수는 **r = 0.641**, 단순회귀 결정계수는 **R² = 0.411**이었습니다.

동대문구는 회귀선 대비 **+52.34건**, 도봉구는 **−45.74건**으로 각각 가장 큰 양·음의 잔차를 보였습니다.

| 2025년 지표 | 동대문구 | 도봉구 |
|---|---:|---:|
| 65세 이상 거주인구 | 72,779명 | 78,335명 |
| 고령 보행자 사고 | **132건** | **38건** |
| 거주인구 1만 명당 사고 | 18.14건 | 4.85건 |
| 평균 65세 이상 생활인구 | 84,782.29명 | 86,811.24명 |
| 생활인구 1만 명당 사고 | 15.57건 | 4.38건 |

사고 *건수*는 약 **3.47배**, 거주인구 기준 발생 수준은 약 **3.74배**, 평균 생활인구 기준 발생 수준은 약 **3.56배** 차이 났습니다. 동대문구의 평균 65세 이상 생활인구는 도봉구보다 약 2.3% 적어 생활인구 규모만으로 사고 격차를 설명하기 어렵습니다.

#### 2022~2025년 사고 건수

| 연도 | 동대문구 | 도봉구 |
|---|---:|---:|
| 2022 | 138건 | 49건 |
| 2023 | 155건 | 61건 |

네 해 모두 동대문구에서 더 많은 사고가 집계됐습니다. 거주인구와 평균 생활인구의 단순 규모 차이만으로 이 격차를 설명하기는 어렵습니다.

행정안전부 API에서 확보한 **서울 노인보호구역 경계 기록은 280건**이었습니다.

| 자치구 | 보호구역 경계 기록 | 65세 이상 거주인구 1만 명당 사고 |

25개 자치구 산점도에서는 **경계 기록 수와 사고 발생 수준 사이에 뚜렷하고 일관된 관계가 관찰되지 않았습니다.** 따라서 경계 기록 수만 비교하기보다 **보호구역의 실제 위치**를 살펴봤습니다.

### 4-4. 핵심 발견: 사고다발지역은 보호구역 경계와 얼마나 겹치는가?

2025년 동대문구의 **보행노인 교통사고 다발지역 10곳** 중 **5곳이 제기동**에 위치했습니다.

사고다발지역 10곳의 경계와 노인보호구역 경계를 직접 비교한 결과는 다음과 같습니다.

| 공간 관계 | 사고다발지역 수 |
|---|---:|
| 보호구역 경계와 겹치거나 접촉 | **3곳** |
| 겹치거나 접촉하지 않음 | **7곳** |
| 합계 | **10곳** |

겹치거나 접촉하는 세 곳은 **동서시장 부근(12건), 청량리전통시장 부근(10건), 떡전교사거리 부근(5건)**으로 확인됐습니다.

도봉구는 사용한 공식 사고다발지역 선정 기준을 충족한 지역이 **0곳**이어서 동일한 공간 중첩 비율을 비교할 수 없었습니다. 이는 도봉구에서 사고가 없었다는 뜻이 아닙니다.

**이번 프로젝트의 핵심 발견은 동대문구의 사고다발지역 10곳 중 7곳이 노인보호구역 경계와 겹치거나 접촉하지 않았다는 사실입니다.** 여기서 곧바로 전체 사고의 70%가 보호구역 밖에서 발생했다거나 보호구역이 사고 예방에 실패했다고 결론 내리지는 않습니다.

### 4-5. 분석 9 — 동대문구 사고다발지역과 가장 가까운 보호구역까지의 거리

### 4-6. 분석 10 — 서울 전체 사고다발지역과 노인보호구역의 공간 비교

**2025년 서울 사고다발지역 71곳**의 GeoJSON Polygon과 **서울 노인보호구역 API 경계 기록 280건**의 WKT Polygon을 비교했습니다. 유효하지 않은 도형은 `make_valid()`로 복구했고, **자치구 경계를 넘어 겹치는 보호구역도 포함**했습니다.

| 공간 관계 | 사고다발지역 수 | 비율 |
|---|---:|---:|
| 면적 중첩 | 12곳 | 16.9% |
| 경계만 접촉 | 0곳 | 0% |
| **비중첩** | **59곳** | **83.1%** |
| 합계 | 71곳 | 100% |

- 사고다발지역이 있는 **21개 자치구 중 11개 자치구**에서는 보호구역과 면적이 겹치는 사고다발지역이 0곳이었습니다.
- 중랑구 **7/7곳**, 은평구 **5/5곳**, 금천구·서대문구 **각 4/4곳**이 비중첩이었습니다.
- 동대문구는 **10곳 중 7곳(70%)** 비중첩으로, 서울 전체 **83.1%보다 낮아** 동대문구만 유독 불일치가 심하다고 볼 수 없었습니다.
- 강남구·광진구·도봉구·서초구는 해당 공식 선정 기준의 사고다발지역이 **0곳**이어서 중첩 비율을 계산할 수 없습니다. 개별 사고가 없었다는 뜻은 아닙니다.

**핵심 발견:** 동대문구에서 시작한 보호구역과 사고 집중지역의 공간적 불일치는 서울 여러 자치구에서도 나타났습니다. 다만 83.1%는 **사고다발지역 폴리곤 수의 비중**이며, **개별 사고의 보호구역 밖 발생 비율**이나 **보호구역 효과의 검증 결과**가 아닙니다.

### 4-7. 분석 11 — 노인보호구역 연도별 지정 명단 비교

서울시 연말 지정 현황(HWPX)을 기준으로 노인보호구역 등재 시설 수를 비교했습니다.

| 기준일 | 명단상 시설 수 |
|---|---:|
| 2022-12-31 | 178곳 |
| 2023-12-31 | 184곳 |
| 2024-12-31 | 195곳 |
| 2025-12-31 | 195곳 |

2022~2025년 명단을 연속 대조하면 **신규 등재 19곳**, **이전 명단에서 제외 2곳**, 순증 **17곳**입니다. 명단에서 빠진 것을 공식 지정 해제로 단정하지 않으며, 명단에 새로 나타난 시점과 정확한 지정 고시일도 구분합니다.

신규 등재 19곳의 시설명을 지정연도보다 앞선 **2022~2024년 선정 사고다발지역** 명칭에 직접 대조했지만 일치 사례는 **0곳**이었습니다. 시설명과 사고다발지역 지점명은 표기 방식이 달라 이것만으로 공간적 관계가 없다고 판단할 수 없습니다.

특히 **2024년 등재 청량리청과물시장**은 공식 지정 명단에는 존재하지만 확보된 보호구역 API 시설·경계 목록에서는 찾지 못했습니다. 따라서 기존 API 경계만으로 산출한 서울 전체 비중첩률(59/71, 83.1%)은 **실제 지정 현황을 빠짐없이 반영한 확정치가 아닙니다.**

### 4-8. 분석 12 — 신규 등재 보호구역과 선행 사고다발지역의 거리

2023~2025년 신규 등재된 시설 **19곳**을 대상으로 지정연도보다 앞서 선정된 **같은 자치구의 2022~2024년 고령 보행자 사고다발지역**과 위치를 비교했습니다.

| 분류 | 시설 수 | 처리 |
|---|---:|---|
| 거리 계산 완료 | **16곳** | 현행 API 보호구역 경계 또는 시설 주소 좌표 활용 |
| 비교 대상 사고다발지역 없음 | **2곳** | 서초구 방배느티나무쉼터·본마을데이케어센터 |
| 위치 미확정 | **1곳** | 청량리청과물시장: 공식 주소가 도로명까지만 제공 |
| 합계 | **19곳** | |

거리 계산 완료 16곳은 **API 보호구역 경계 ↔ 사고다발지역 경계 7곳**, **시설 주소 좌표 → 사고다발지역 경계 9곳**으로 나뉩니다. 측정 기준이 달라 전체를 동일한 경계 중첩 판정으로 해석할 수 없습니다.

가장 가까운 사례는 **2024년 명단 신규 등재된 관악구 예닮노인교실**로, **2023년 선정된 관악구 신원동 진승재치과의원 부근 사고다발지역까지 시설 주소 좌표 기준 73.2m**였습니다. 다음으로 영풍노인정 479.3m, 녹색경로당 876.1m, 문정노인종합복지관 879.1m 등이 확인됐습니다. 16곳 모두 계산된 거리는 0m보다 컸지만, **시설 좌표 기반 9곳의 실제 보호구역 경계 중첩 여부는 확인할 수 없습니다.**

이 결과는 두 대상의 **직선 최단거리**이지 보행 경로 거리나 사고 원인의 증거가 아닙니다. 같은 자치구 및 사용 가능한 선정연도로 비교 범위를 제한했으며, 선정연도를 곧바로 개별 사고 발생연도로 해석하지 않습니다. 신규 지정의 원인이 사고다발지역 선정 때문인지도 이 분석으로는 판단할 수 없습니다.

### 4-9. 분석 13 — 지정·관리 판단 근거 추적 (진행 중)

2026년 11월 11일 기준, 노인보호구역 지정·관리 판단에 **사고 발생 현황이 어떻게 반영되는지** 확인하는 단계입니다.

- **법령 검토:** 「어린이·노인 및 장애인 보호구역의 지정 및 관리에 관한 규칙」 제3조에 따라 시설 운영자 등의 지정 신청, 주변 도로의 연간 교통사고 현황 등 조사, 관계기관 협의 등 지정 절차를 검토했습니다. 법령에 조사 절차가 있다는 사실은 개별 구역에서 어떤 자료를 검토했는지에 대한 증거와 구분합니다.
- **공개 행정자료 검토:** 서울시 2022년 7월 도시교통실 업무보고에 노인보호구역 신규·확대 지정과 보호구역 개선, 교통사고 잦은 곳 개선 등이 **서로 다른 사업 유형**으로 제시된 사실을 확인했습니다. 따라서 신규 보호구역 지정 여부만으로 지자체의 사고 위험지점 대응 전체를 평가하지 않습니다.
- **정보공개청구:** 사용자가 **서울특별시를 대상으로 2023~2025년 신규 등재 시설 19곳의 지정 검토·교통사고 조사·선정 근거·지정 구간 및 안전시설 개선 관련 자료를 청구했다고 확인**했습니다. 접수번호·답변·원문은 아직 확보되지 않았으므로 청구 내용은 답변을 받은 것으로 기록하지 않습니다.
- **현재 상태:** 답변 대기. 신규 등재 19곳에서 사고자료가 실제 지정 의사결정에 어떻게 사용됐는지, 보호구역 외 별도 안전시설 개선이 이뤄졌는지는 **미확인**입니다.

참고 공개자료: [국가법령정보센터 보호구역 지정·관리 규칙](https://www.law.go.kr/법령/어린이ㆍ노인및장애인보호구역의지정및관리에관한규칙), [서울시 도시교통실 주요 업무보고(2022.7.19)](https://mas.smc.seoul.kr/attach/record/SEOUL/appendix/a11/A0056869.pdf).

**다음 행동:** 정보공개청구 답변이 도착하면 실제 공개 문서의 지정 사유·사고 조사·사업 이력을 기존 분석 11·12의 위치 관계와 대조하고, 그 결과만 반영해 분석 13을 마무리합니다.

### 4-10. 후속 연구 — 노인보호구역 지정 후 고령 보행자 사고가 감소했는가? (진행 중)

**연구 질문:** 같은 노인보호구역의 실제 지정 전후 고령 보행자 사고 건수와 심각도가 어떻게 달라졌는가? 분석 1~12 및 지정 판단 근거를 추적하는 분석 13과 구분하는 후속 연구입니다.

**기존 데이터 검토·가공:** 2022~2025년 동대문구·도봉구 사고 상세 엑셀에는 발생연월·사고 심각도·사고유형이 있으나 **개별 사고 좌표는 없습니다**. 2012~2025년 전국 고령 보행자 사고다발지역 CSV에는 사고다발지역 폴리곤·집계 사고건수·사상자 정보가 있으나 **개별 사고 날짜·위치는 없습니다**. 원본에서 서울 기록 **1,554행**을 추출하고 수치·좌표를 정리했으며 좌표 누락은 **0행**입니다. 가공된 CSV는 Colab 작업 환경에 생성됐고, **GitHub 반영 여부는 별도 확인이 필요합니다**.

**탐색적 공간 연결:** 기존 노인보호구역 API 경계를 확보한 2023~2024년 신규 등재 시설 9곳을 대상으로 사고다발지역 폴리곤과의 직선 최단거리 **300m 이내** 선정 기록을 조회했습니다. 2021~2026년 사고다발지역 ID 기준 9곳 중 **거여경로당 1곳**에서 기록이 발견됐고, 나머지 8곳은 해당 범위·연도의 선정 기록이 없었습니다. 300m는 탐색을 위한 임의 반경이며 보호구역의 공식 지정 범위가 아닙니다.

| 거여경로당 주변 기록의 ID 연도 | 사고다발지역 | 사고다발지역 집계 사고건수 | 사망자수 | 보호구역 경계와 최단거리 |
|---|---|---:|---:|---:|
| 2023 | 송파구 거여2동 거성교회 부근 | 5건 | 0명 | 101.8m |
| 2025 | 송파구 거여동 거여역교차로 부근 | 5건 | 1명 | 63.1m |
| 2026 | 송파구 거여동 거여역교차로 부근 | 5건 | 2명 | 55.7m |

**해석 주의:** 위 수치는 사고다발지역 **선정 자료의 집계치**이지 보호구역 안에서 특정 연도에 발생한 개별 사고 건수가 아닙니다. 선정 ID 연도와 실제 사고 집계기간의 대응을 아직 확인하지 못했고, 2025·2026년 기록을 서로 독립적인 사고 10건으로 합산할 수도 없습니다. 반복 선정이나 선정 기록 부재로 보호구역의 사고 감소 효과를 확정하지 않습니다.

**TAAS 화면 시험:** 보호구역의 *효과분석* 기능은 지정 도로와 주변 300m 내 지정 외 도로 사고를 구분했지만, 지정일이 누락된 시설이 있고 비교 기간을 임의로 바꿀 수 없었습니다. 예닮노인교실(공식 명단상 2024년 지정)의 TAAS 화면에서 2024→2025년 **지정 도로 노인 보행자 사고 0→0건, 지정 외 도로 2→5건**이 표시됐습니다. **2024년은 지정연도이므로 유효한 지정 전후 비교가 아니며**, 주변 사고를 지정 구역 내부 사고로 취급할 수 없습니다.

**집계 단절 위험:** TAAS는 **2025년부터 보호구역 해당 여부 확인이 시스템화됨에 따라 보호구역 사고 통계가 증가할 수 있다**고 안내합니다. 따라서 2024~2025년 보호구역 내 사고 수치 변화를 실제 사고 위험의 증감으로 단정하지 않습니다. 서울 공식 연말 명단의 노인보호구역 시설 수는 2024년·2025년 모두 195곳이나, 경계 확대 여부와 전국 지정 규모 변화까지 설명하지는 못합니다.

**외부 자료 요청:** 사용자가 **한국도로교통공단에 보호구역별 연도별 고령 보행자 사고 통계, 지정 전후 비교 가능 여부 및 2025년 집계 방식 관련 정보공개청구를 접수했다고 확인**했습니다. 현재 **답변 대기**이며, 자료 제공이나 사고 예방 효과는 아직 확인되지 않았습니다.

**다음 작업:** 공단 답변으로 동일 보호구역·동일 공간·비교 가능한 기간의 사고 건수를 확보할 수 있는지 먼저 판정하고, 가능할 때만 지정 전후 사고 감소 및 반복 사고 여부를 분석합니다. 후속 분석의 완료 조건은 **실제 사고 변화에 대한 판단(또는 자료 한계에 따른 불가능 판정)과 노트북·README·가공 데이터의 원격 GitHub 반영 확인**입니다.

### 현재의 취재 질문

> **사고는 보호구역 밖에서 집중된다 — 노인보호구역은 어디를 보호하고 있나?**

이 제목의 ‘사고’는 **서울의 공식 고령 보행자 사고다발지역 폴리곤**을 뜻합니다. 59/71이라는 수치를 모든 개별 사고의 위치 비율로 확대 해석하지 않습니다.

### 다음 작업: 정보공개청구 답변을 통한 분석 13 검증

분석 13의 법령·공개자료 1차 검토와 정보공개청구 제출까지 진행했습니다. **답변이 도착하면 실제 지정 검토자료와 사업 이력을 분석 11·12에 연결**합니다. 그 전까지 행정기관이 사고다발지역을 반영했는지 여부를 단정하지 않습니다.

## 6. 분석의 한계

- **공간 범위:** 공식 사고다발지역 71곳은 서울의 전체 개별 사고 지점을 나타내지 않습니다. 동대문구의 3곳은 경계만 접촉한 것이 아니라 실제 면적이 겹쳤습니다.
- **지정 기록:** API 경계 기록 수는 공식 지정 시설 수와 다를 수 있고, API 기준일이 혼재되어 **2025년 당시의 지정 현황**과 반드시 같지 않습니다. 공식 명단에 등재된 청량리청과물시장이 API에서 확인되지 않아 83.1%의 확정적 일반화를 피해야 합니다.
- **연도별·거리 비교:** 연말 명단의 신규 등재는 실제 지정 고시일과 같지 않을 수 있습니다. 과거 사고다발지역은 선정연도 기준이며, 일부 시설은 경계가 아닌 주소 좌표로 측정했고 같은 자치구 내 후보만 비교했습니다.
- **인구 지표:** 사고는 발생 지역 기준, 거주인구는 거주지 기준입니다. 평균 생활인구는 체류 규모의 추정치로 실제 보행량·횡단 횟수가 아닙니다.
- **생활인구 범위:** 생활인구는 내국인 추정치이고 거주인구와 집계 대상이 완전히 일치하지 않습니다. 생활인구/거주인구 비율은 거주자 체류율이 아닙니다.
- **해석 범위:** 보호구역 경계와 사고다발지역이 어긋난다는 사실은 지정 범위를 검토할 근거지만, 개별 구역의 지정 적격성이나 보호구역 정책의 예방 효과를 판정하지는 않습니다. 상관·회귀분석도 사고 원인을 확정하지 않습니다.

## 7. 분석 환경 및 후속 구현 목표

- **현재 분석:** Python, pandas, Google Colab, Jupyter Notebook ([`analysis.ipynb`](analysis.ipynb))
- **공간정보:** GeoJSON Polygon·WKT Polygon의 면적 중첩/접촉 판정, EPSG:5179에서 폴리곤 사이 최단거리 계산; Colab 지도 및 서울 자치구별 시각화 구현
- **후속 구현 목표:** 검증된 사실표·연구자료를 출처와 함께 검색하는 RAG 챗봇(미구현)
- **현재 구현 상태:** 기존 CSV 기반 Streamlit 탐색 대시보드의 첫 버전은 구현·로컬 실행 확인을 마쳤습니다. RAG 챗봇과 보호구역 지정의 인과효과 분석은 아직 구현·검증되지 않았습니다.

프로젝트의 목적은 노인보호구역의 효과를 미리 단정하는 것이 아니라, **공공데이터를 결합해 사고 집중지역과 행정적 보호 범위 사이의 관계를 드러내고 다음 취재 질문을 만드는 것**입니다.

## 8. Streamlit 탐색 대시보드 실행

기존 `data/processed/` CSV를 활용하는 로컬 웹 대시보드입니다. 지역·연도별 사고 통계, 노인보호구역 및 사고다발지역 지도, 중첩·비중첩 현황, 지정 전후 *사고다발지역 선정 기록*의 탐색 화면을 제공합니다.

Windows PowerShell에서 저장소 루트로 이동한 뒤 실행합니다.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저에서 [http://localhost:8501](http://localhost:8501)에 접속하고 왼쪽 사이드바에서 페이지·사고연도·자치구를 선택하세요. 필수 가공 파일은 `data/processed/`의 `01_자치구연도_패널.csv`, `03_다발지역_서울.csv`, `04_보호구역_마스터.csv`, `05_보호구역_경계.csv`, `06_다발지역_보호구역_연결.csv`입니다. 원본 데이터와 기존 분석 스크립트를 다시 실행할 필요는 없습니다.

**로컬 확인 기준:** 2025년·서울 전체·공간 분석 지도에서 사고다발지역 71곳, API 경계 중첩 12곳, 비중첩 59곳이 표시됨을 확인했습니다. 이는 *사고다발지역 수*의 분류로, 개별 사고 중 보호구역 밖 발생 비율이 아닙니다.

**해석 한계:** 2022~2024년 자치구별 고령 보행자 사고건수는 동대문구·도봉구만 확보됐습니다. 사고다발지역 선정 기준은 연도에 따라 달랐고, 지도는 과거 경계가 아니라 확보한 API 경계를 표시합니다. API 경계는 공식 지정 시설을 모두 포함하지 않을 수 있습니다. 현재 자료만으로 보호구역 지정 후 실제 사고 감소 효과를 판단할 수 없습니다.
