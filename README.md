
# 서울 고령 보행자 교통사고 분석

## 1. 프로젝트 소개

### 핵심 질문
**동대문구는 왜 고령 보행자 사고가 가장 많이 발생한 지역인가?**

2025년 서울 25개 자치구의 고령 보행자 교통사고 데이터를 분석해 지역별 사고 발생 수준을 비교하고, 추가 취재가 필요한 문제를 발굴하는 데이터 저널리즘 프로젝트입니다.

단순 사고 건수뿐 아니라 고령인구 규모를 고려해 비교합니다.

## 2. 데이터 출처

- 한국도로교통공단 TAAS: 2025년 시군구별 고령 보행자 교통사고 통계
- 서울 열린데이터광장: 2025년 4분기 자치구별 65세 이상 인구 현황

원본 데이터는 `data/` 폴더에 보관합니다.

## 3. 분석 방법

Python과 pandas를 사용했습니다.

1. 서울 25개 자치구의 고령 보행자 사고 건수를 추출
2. 2025년 65세 이상 인구 데이터 정리
3. 자치구 이름을 기준으로 두 데이터 결합
4. 고령인구 1만 명당 사고 건수 계산
5. 사고 건수 순위와 인구 대비 순위 비교

계산식:

고령인구 1만 명당 사고 건수 = 사고 건수 / 65세 이상 인구 × 10,000

분석 코드는 `analysis.ipynb`에서 확인할 수 있습니다.

## 4. 주요 발견 (1차 분석)

### 동대문구: 사고 건수 1위, 인구 대비 2위

2025년 서울 동대문구에서 발생한 고령 보행자 사고는 132건으로 25개 자치구 중 가장 많았습니다.

65세 이상 인구 72,779명을 기준으로 계산한 인구 1만 명당 사고 건수는 18.14건으로, 중구에 이어 두 번째였습니다.

동대문구의 높은 사고 건수는 거주 고령인구 규모만으로 설명하기 어렵습니다.

### 중구: 사고 건수 18위, 인구 대비 1위

중구의 고령 보행자 사고는 61건으로 서울 18위였으나, 고령인구 1만 명당 22.08건으로 1위를 기록했습니다.

단순 사고 건수 순위와 인구 대비 순위가 크게 달라질 수 있음을 확인했습니다.

## 6. 분석의 한계

- 사고는 발생 지역 기준이며, 인구는 거주지 기준입니다.
- 유동인구와 실제 고령자 보행량이 반영되지 않았습니다.
- 인구는 2025년 4분기 기준이며 사고는 2025년 연간 통계입니다.
- 인구 대비 사고 건수는 개인의 사고 확률을 직접 의미하지 않습니다.
- 사고 발생 원인과 지역의 보행환경은 추가 자료 및 현장 취재로 확인해야 합니다.
